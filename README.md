# paseo-plugin-sync

Paseo plugin that keeps plugin installations in sync across hosts through a GitHub repository.

See `OVERVIEW.md` for behavior. Install on each daemon:

```bash
paseo plugin install git:https://gh.imtsui.com/https://github.com/repairer7/paseo-plugin-sync.git
```
